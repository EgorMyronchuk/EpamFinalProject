# Online Book Store (Spring Boot)

### Важливо
Финальна версія проєкту зі всіма актуальними змінами та виправленнями знаходиться у гілці: **`toDefence`**.

---

## Опис проєкту
Самостійно спроєктував та розробив повноцінний вебдодаток із багаторівневою архітектурою. Впровадив комплексну систему безпеки: **HTTPS (SSL)**, **JWT (Access/Refresh)** та **OAuth2 (Google Auth)** із використанням **HttpOnly Cookies**. Розробив адаптивний фронтенд на **Thymeleaf** із підтримкою багатомовності (**i18n**), системою сповіщень та рольовим доступом (**Admin / Employee / User**).

Використав стек **Spring Boot, Security, Data JPA, PostgreSQL та Liquibase**. Реалізував гнучку фільтрацію через **JPA Specifications**, управління транзакціями (**@Transactional**) та каскадні операції. Налаштував розділення конфігурацій (**Dev/Prod profiles**) та автоматизацію міграцій БД, забезпечивши стабільну роботу та масштабованість системи.

## Основні технології
* **Backend:** Java 17, Spring Boot 3, Spring Security (JWT + OAuth2).
* **Database:** PostgreSQL, Liquibase (migration tool), H2 (for Dev).
* **Frontend:** Thymeleaf, CSS3 (Flexbox/Grid), JavaScript.
* **Tools:** Maven, Lombok, MapStruct.

## Функціонал
* **Безпека:** Повна авторизація через власну базу або Google Account. Захист токенів через HttpOnly Cookies.
* **Ролі:** * *Admin:* Управління персоналом.
    * *Employee:* Керування асортиментом книг та замовленнями.
    * *User:* Пошук, фільтрація, кошик та купівля книг.
* **Локалізація:** Повна підтримка української та англійської мов.
* **Фільтрація:** Динамічний пошук за ціною, жанрами, мовою та віковими групами.
